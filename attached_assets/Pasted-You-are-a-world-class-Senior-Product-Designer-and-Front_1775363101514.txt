You are a world-class Senior Product Designer and Frontend Architect with experience building award-winning startup products.

Your task is to completely refine, redesign, and polish the existing frontend UI/UX to achieve a premium, modern, and production-ready look — comparable to top-tier SaaS startups.

🎯 CORE OBJECTIVE:
Transform the UI into a visually stunning, highly intuitive, and smooth user experience while maintaining simplicity and clarity. Avoid clutter, avoid excessive cards/grids, and focus on clean, structured layouts.

---

🧠 DESIGN PRINCIPLES:

1. MINIMALISM FIRST
- Avoid heavy use of cards and grid layouts.
- Use cards ONLY where absolutely necessary (e.g., key highlights, summaries).
- Prefer whitespace, typography hierarchy, and section separation instead of boxes.

2. VISUAL HIERARCHY
- Strong typography scale (headlines, subtext, captions).
- Clear spacing system (8px or 10px scale).
- Use contrast and font weight instead of borders.

3. STARTUP-GRADE AESTHETICS
- Clean, modern, elegant UI (inspired by Stripe, Linear, Notion).
- Subtle shadows, soft borders, and smooth gradients (not loud).
- Consistent color system (primary, secondary, neutral, accent).

4. SMOOTH UX & FLOW
- Every screen must feel connected and purposeful.
- Remove friction in navigation.
- Optimize user journey from entry → action → result.

5. MICRO-INTERACTIONS
- Add subtle hover effects, transitions, and animations.
- Use motion for feedback (button click, loading, success states).
- Keep animations fast and meaningful (no laggy effects).

---

🎨 LAYOUT GUIDELINES:

- Prefer vertical flow over grid clutter.
- Use split layouts (left navigation + right content).
- Use sections with clear spacing instead of boxed UI.
- Maintain consistent alignment and padding.

---

⚡ UX IMPROVEMENTS:

- Reduce cognitive load.
- Eliminate unnecessary elements.
- Ensure every component has a purpose.
- Improve readability and accessibility.
- Make actions obvious (CTA clarity).

---

🔍 QUALITY CHECKS:

- No cluttered UI.
- No inconsistent spacing.
- No random colors or mismatched fonts.
- No overuse of borders or cards.
- No broken flows or confusing navigation.

---

🔥 ADVANCED ENHANCEMENTS:

- Add skeleton loaders instead of spinners.
- Add empty states with meaningful guidance.
- Add success/error feedback with clarity.
- Ensure responsiveness across all devices.
- Maintain pixel-perfect alignment.

---

🛠️ TECH EXPECTATIONS:

- Use modern frontend practices (React + Tailwind or equivalent).
- Maintain clean, reusable components.
- Follow design system consistency.
- Optimize performance (lazy loading, minimal re-renders).

---

🎯 FINAL GOAL:

The UI should feel like a premium SaaS product:
- Clean like Notion
- Fast like Linear
- Polished like Stripe

It should impress users at first glance and feel effortless to use.

Deliver a refined UI/UX that looks stunning, professional, and startup-ready without over-designing.
